# Python Dice Game

A simple command-line dice game written in Python.

## Features

- Randomly selects one of six dice faces.
- Displays the result as a 3×3 grid in the terminal.

## Requirements

- Python 3

## How to Run

```bash
python3 dice-game.py
```

## What I Practised

Nested lists, loops, random selection, and console output.

## Purpose

A small project created as part of my Python learning journey.
